# Forage iOS: architecture

Native SwiftUI client for the Forage web app. iOS 26+, Swift 6 strict concurrency, `@Observable`,
async/await `URLSession`, XcodeGen, **no third-party packages**. It calls the web JSON API
(`/api/*`) with the same session cookie. The patterns are copied from the Lodestar app
(`~/Documents/GitHub/lodestar/ios`, read-only for us): same networking client, cookie session,
error funnel, account screens and AI sign-in. Endpoint behaviour and copy live in `docs/api.md`;
this file owns how the app is put together.

## Cost rule

Everything is free:

- Maps: **MapKit** (`Map`, `Marker`, `MapCameraPosition`, `MKMapItem.openInMaps`). No MapLibre,
  no Google Maps SDK, no tile keys.
- Location: **CoreLocation** (`CLLocationManager`, when-in-use only, `kCLLocationAccuracyHundredMeters`).
- Place data: Forage's own `/api/places*` (OpenStreetMap). The app never calls Google. Google live
  details appear only if the server owner sets `GOOGLE_PLACES_KEY`; the app just renders `live`.
- Area search: the server's `/api/explore/geocode` (Photon, free). `MKLocalSearchCompleter` is a free
  fallback but not used in v1.
- AI: the user's own ChatGPT/Grok subscription through the server. No server AI key, no SDK.
- Fonts: Geist, Geist Mono (OFL, same files as Lodestar) and Newsreader (OFL, Google Fonts) bundled.
- No analytics, crash or ads SDKs.

## Build and test

```bash
cd ios
xcodegen generate
xcodebuild -project Forage.xcodeproj -scheme Forage \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath /tmp/forage-ios-dd-<label> -jobs 4 build     # or: test
```

Sources are folder globs; re-run `xcodegen generate` after adding files. Tests use Swift Testing in
`ForageTests/`, never touch the network (stubbed `URLProtocol`), one suite per file. Use one simulator
at most and shut it down afterwards. Debug builds accept `-ForageTab near|explore|lists|ask|account`,
`-ForageDebugAccount "email password"` and `-ForageSheet log|place:<id>` (`App/AppState+Debug.swift`).

### Ownership rules (parallel work)

Same as Lodestar: each feature agent edits only `Forage/Features/<Name>/` and adds tests under
`ForageTests/<Name>/`. `App/`, `Core/` and `UI/` are shared and built first by one agent; feature
agents don't edit them and list anything they had to add locally so it can be promoted. Keep the
placeholder type names `RootView` references (`NearRootView()`, `ExploreRootView()`, `ListsRootView()`,
`AskRootView()`, `AccountRootView()`, `SignInSheet(startMode:)`, `AIConnectSheet(provider:)`,
`PlaceDetailView(placeId:)`, `LogVisitSheet(placeId:)`). Prefix types that could collide (`NearModel`, `ExploreModel`). No
backend changes: report gaps.

## Talking to the API

Copied from Lodestar's `Core/Networking` with the names changed:

- `APIClient` (one per app, `AppState.api`) owns one `URLSession` on a private in-memory cookie store
  (an ephemeral configuration's) with `httpShouldSetCookies = true`, so `fg_session`, `fg_device`, the
  AI cookies and `fg_lodestar_flow` flow on every call. Unlike Lodestar it does not use
  `HTTPCookieStorage.shared`, which is written in plain form to Library/Cookies and backed up.
  `CookieVault` saves the cookies that have an expiry date to the Keychain
  (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`) after every response and restores them at
  launch; sign-out deletes `fg_session` and saves again. It never sends `Origin`. Non-GET calls without a body send `{}`. JSON bodies use
  `Content-Type: application/json`. `DELETE /api/want` and `DELETE /api/account` carry a body.
- `send(_ endpoint) async throws -> T` unwraps `data` via `ResponseDecoder`. Errors are `APIError`
  with a user-facing `.message` ("Request failed (HTTP n).", "Can't reach Forage. Check your
  connection.", or the server's sentence) or `CancellationError`.
- `APIError.isSignInRequired`: status 401 **and** message "Sign in first.". Only this drops the app to
  signed out. `APIError.needsAIConnection`: 401 whose message starts with "Connect" (AI not connected);
  respond with `app.present(.connectAI)`. `isRateLimited`: 429, show and never auto-retry.
- `Timeouts`: `.standard` 30 s, `.places` 45 s, `.recs` 90 s, `.ai` 150 s (see api.md §0).
- Every caught error goes through `app.handle(error)` (returns the message or nil for cancellation).
- No streaming routes and no image routes in Forage, so Lodestar's `stream` and `ImageLoader` are
  not copied.

```swift
@Environment(AppState.self) private var app
let page = try await app.api.send(API.Recs.near(NearRequest(lat:, lng:, filter: .new)))   // RecsPage
let step = try await app.api.send(API.Visits.log(VisitInput(...)))                          // LogResponse
```

## AppState

`@MainActor @Observable final class AppState`, injected at the root, read with
`@Environment(AppState.self) private var app`. Mirrors Lodestar's.

| Member | Use |
|---|---|
| `api` | the shared client |
| `session` (`.checking/.signedOut/.signedIn(user)`), `isSignedIn` | decided only by `GET /api/account` at launch and after sign-in actions |
| `aiStatus` | `refreshAIStatus()` at launch, after connect/disconnect, sign-in and sign-out |
| `lodestar` | `LodestarStatus?`; `refreshLodestar()` on Account appear and after connect/disconnect/409 |
| `location` | `LocationService`: `authorization`, `current` (`LatLng?`), `requestFix() async -> LatLng?`. Near me, Log search and Ask share it |
| `selectedTab`, `sheet`, `present(_:)` | tabs `near, explore, lists, log, ask, account`; sheets `.signIn`, `.register`, `.connectAI`, `.connectLodestar`, `.place(id)` |
| `listsRevision` | bumped after any visit/want write so Lists and Near me reload |
| `signIn`, `register`, `signOut`, `signOutEverywhereElse`, `deleteAccount(password:)`, `requestPasswordReset(email:)`, `resetPassword(token:password:)`, `disconnectAI(_:)` | session actions; throw `APIError` for the screen to show |
| `handle(_:)` | the error funnel |

Signed out, the app shows only Account (sign in / register / forgot / reset) and Connect AI. Every
other tab needs a session: show a sign-in prompt in place of the tab content, not an error.

Feature screen state lives in the feature: an `@MainActor @Observable final class` model per screen,
created with `@State`, holding `LoadState<Value>` and calling `app.api`. Cancel the in-flight `Task`
when a newer request replaces it (search-as-you-type, filter changes) and drop stale answers.

## Connect Lodestar

`Features/Lodestar/LodestarNativeConnect.swift`: `POST /api/lodestar/connect` → `ASWebAuthenticationSession`
→ `POST /oauth/lodestar/callback {code, state, iss}` → refresh status. This needs a small web change
(a JSON `POST` on the callback route plus the AASA `webcredentials` entry); see `api.md` §11. It is
written but off (`LodestarConnectLogic.nativeCallbackAvailable = false`). Until the web change lands,
Connect uses `LodestarWebConnectView.swift`: an in-app web view seeded with the app's cookies that
catches the redirect to `/account?lodestar=<outcome>`. Delete that file and flip the flag once the
web change ships.

## Design system (Ledger)

Follows `~/DESIGN.md` (there is no `forage/DESIGN.md`) with the exact token values in the web's
`app/globals.css`. Dark is the default look; light follows the system, with an `@AppStorage` theme
override like Lodestar's `ThemePreference`.

- **Colors** (`Color.<token>`, light/dark pairs in the asset catalog): `canvas #0E0E0D/#F7F5EF`,
  `card #141413/#FBFAF6`, `hover #1A1A18/#EFECE4`, `deep`, `ink #F2F0EA/#16161A`, `body` (86%),
  `mute` (55%/64%), `stone` (28%), `line` (8%/10%), `line2` (18%/22%), `field` (42%/50%), `primary`,
  `primaryOn`, `primaryHover`, `accent #4C8DFF/#2A63CC`, `accentHover`, `accentOn`, `wash`, `ok`,
  `danger`, `warn`, `scrim`. Blue is the only color; `ok/danger/warn` only for state.
- **Type**: Newsreader for what people read (screen titles, place names on detail, AI reasons, taste
  summary, empty states); Geist for controls and UI text; Geist Mono for every number, date, score,
  distance, price and label (sentence case, never uppercase-tracked). `.textStyle(...)` sets face,
  size, tracking and line spacing with Dynamic Type, as in Lodestar's `Typography.swift`, with the
  serif face swapped from Geist Serif to Newsreader.
- **Metrics**: spacing scale 4/8/12/16/24/32/48, gutter 16; radii 4 (controls), 6 (panels, wells,
  sheets' inner panels), full for pills, never above 6 otherwise; controls 44 pt tall on touch;
  hairlines 1 pt. Motion 150 ms `(0.2, 0, 0, 1)`, enter 200 ms with a 6 pt rise, Reduce Motion honoured.
- **Layout**: rules over boxes. Sections open with a `line2` hairline and a mono label (left) and real
  meta (right). Lists are hairline rows, not cards. Boxes only for inputs and tappable objects. No
  shadows, gradients, blur or glass; overlays use a flat `scrim`.
- **Components**: `.buttonStyle(.forage(.primary | .accent | .ghost | .link | .destructive))` (one
  primary or accent per screen), `ForageField` (error text in `danger` mono 12 below),
  `SectionRule(label:meta:)`, `PlaceRow`, `RecRow`, `Pill` (filters/status, mono 12, full radius),
  `ScoreText` (mono, tabular, one decimal), `ReactionPicker`, `OccasionPicker` (segmented),
  `LoadState`, `EmptyStateView` (Newsreader line + one ghost action), loading blocks with a 1.6 s
  opacity breathe (no shimmer, spinners only inside buttons).
- **Tab bar**: system `TabView` with SF Symbols (`location`, `map`, `list.bullet`, `plus.circle`,
  `text.bubble`, `person`), tinted `accent`. Copy: "Near me", "Explore", "Lists", "Log", "Ask", "Account".

## Conventions

Lodestar's, unchanged: files 200–400 lines (800 max), functions under ~50 lines, value types and new
values instead of mutation, every `try` caught and shown, no hardcoded secrets, copy verbatim from the
web (iOS wording "Tap", "on this device"), no exclamation marks or emoji, `nonisolated static` for pure
helpers tested off the main actor, accessibility labels on icon buttons, Dynamic Type.

Port and test the web's pure helpers: `BeenRow` grouping, tag label formatting, reset-token
extraction, AI callback parsing (`AIConnectLogic`), Lodestar callback parsing.

## Known gaps (no backend changes from the app agents)

- **Connect Lodestar** needs the web change in `api.md` §11 before it works natively.
- **AI sign-in** loopback listener is untested on a device (same as Lodestar); the paste fallback works.
- **Password reset links** are `https://…/reset?token=` and open Safari until the web serves
  `/.well-known/apple-app-site-association` with `applinks` for `/reset` and the app gets the
  associated-domains entitlement. Until then Account offers a paste field; `forage://reset?token=…`
  is handled for manual testing.
- **Places OpenStreetMap lacks** can't be added (same as the web).
- **Google live details** depend on the server key; without it the place screen shows OSM data only.
- **Location**: when-in-use only; no background location, no region monitoring.
